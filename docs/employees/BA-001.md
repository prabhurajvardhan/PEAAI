## ⚠️ Fix Required for PR #16

### Problem
Python AI code (M08) was placed in `src/ai/` instead of `backend/ai/`.

This violates project architecture where:
- `src/` = TypeScript/frontend code
- `backend/` = Python/backend code

All other backend modules are in `backend/`:
- `backend/api/`
- `backend/auth/`
- `backend/database/`
- `backend/session/`
- `backend/storage/`
- `backend/websocket/`

### Solution

1. **Move the AI module from `src/ai/` to `backend/ai/`:**
   ```bash
   git mv src/ai backend/ai
   ```

2. **Update any internal imports if needed**

3. **Commit and push:**
   ```bash
   git add -A
   git commit -m "fix: Move AI module from src/ai to backend/ai"
   git push origin feature/m08-ai-engine
   ```

4. **Verify:**
   - No Python files in `src/`
   - `backend/ai/` contains all AI module files
   - Tests still pass

### Why This Matters
- Consistent folder structure
- Separate deploy pipelines (frontend vs backend)
- Clear module boundaries
- Team ownership alignment (Backend & AI Engineering → `backend/`)
